# hosts/ipados — wasmtime on Pulley, a SwiftUI shell (implementation M6)

The engine-matrix decision (2026-08-27): iOS permits neither JIT nor
runtime-AOT, so wasmtime runs its Pulley interpreter backend with
`signals_based_traps(false)` — pure, lawful, slower (the slowdown gets
measured into RESEARCH, and the matrix names wasmi as fallback). User-granted
folders arrive as security-scoped bookmarks surfaced as binds: a granted
subtree IS a bind. Inherits the presentation shape from hosts/macos (M3).
