## The gap that prompted the second reading

The lenses ran on **three days in August and then not at all** — through the
compositor redesign, the type system and the layering, which were the largest
design work in the project. The cadence they set for themselves is *"one review
ritual, three lenses, run together"*, triggered by **each shipped form**.

**2026-09-02 closed that gap**, on a subject Christine bounded deliberately:
*is the design enough to rebuild the demo?* Its answer was **no, by two named
gaps** — the status line has no specification, and layout placement is not
expressible — plus two smaller ones inside the demo's boundary. Everything
outside it was parked rather than examined, which is what a bounded reading is
for.

**The next reading should not wait to be asked.**
